# Day 8 Reflection

The most difficult concept in this course was understanding how a system handles many users trying to access the same resource at the same time. Before learning system design, I did not fully understand how two people could try to buy the same concert seat or why simply checking whether a seat was available was not enough. I overcame this challenge by breaking the process into smaller steps and learning how database transactions, locks, and unique constraints work together. Designing TicketHub helped me connect these concepts to a real-world problem.

Based on my experience with my AZ-900 Flashcard Coach capstone, I would improve the testing and reliability of the application. I encountered issues involving repeated flashcard questions and progress tracking. I would add more automated tests to check that different study cards appear correctly, revision mode prioritizes cards that need practice, and progress remains accurate after refreshing the page. I would also test how the application behaves when users make repeated requests or when something goes wrong.

Next, I want to learn more about databases, SQL, and backend development. I would like to understand how to build APIs that connect a frontend to a database and how authentication protects user accounts. I also want to practise deploying applications to the cloud and monitoring their performance. These skills will help me build applications that are not only attractive and useful but also secure, reliable, and able to handle many users.
