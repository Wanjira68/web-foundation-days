# QuickNotes

QuickNotes is a simple note-taking app that lets users create, search, and delete notes by category. Notes are saved in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, or Study categories
- Display the date and time each note was created
- Delete notes
- Search notes as you type
- Search is case-insensitive
- Validate empty notes and notes over 200 characters
- Save notes using localStorage
- Display the number of notes
- Responsive layout for smaller screens

## How to Run Locally

1. Clone or download the repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser.
